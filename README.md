# Desafío 03

Aplicación Android desarrollada como último desafío práctico del curso. El proyecto aplica los conocimientos adquiridos durante el módulo, utilizando Kotlin y Android Studio.

## Funcionalidades

- Interfaz de usuario con varias pantallas
- Navegación entre pantallas
- Manejo y validación de datos ingresados por el usuario

## Tecnologías utilizadas

- Android Studio
- Kotlin
- Gradle (Kotlin DSL)

## Cómo ejecutar el proyecto

1. Clona el repositorio.
2. Ábrelo en Android Studio.
3. Espera a que Gradle sincronice.
4. Ejecuta la app en un emulador o celular.
